                    <details class="um-det">
                        <summary>مدينة نصر، القاهرة (مصر) · أول توسع عمراني مخطط شرق القاهرة</summary>
                        <div class="um-in text-xs sm:text-sm space-y-2 leading-loose">
                            <p>بدأ التطوير في الستينيات كأحد أوائل «المدن التوأم» الحكومية لتخفيف الضغط عن وسط القاهرة، على أرض صحراوية بطريق المطار بين العباسية ومصر الجديدة، بمساحة أصلية نحو <b>6,300 فدان (≈ 26.5 كم²)</b>. النمو تجاوز المخطط الأصلي مبكراً، فامتدت الحدود عام 1971 بإضافة نحو <b>14,000 فدان</b> أخرى، وما زالت تتوسع شرقاً.</p>
                            <p>المساحة الحالية للمنطقة حسب ويكيبيديا العربية نحو <b>250 كم²</b> (تشمل كل التوسعات والأحياء الملحقة)، والسكان <b>732,820 نسمة</b> (تعداد يناير 2023) بكثافة إجمالية ≈ <b>29 نسمة/هكتار</b>، أي في نطاق «الضواحي» على مقياس الكثافة داخل المنصة.</p>
                            <p class="text-amber-300/90"><b>الدروس التخطيطية:</b> سكن الموظفين والتعاونيات سرّع التنمية، لكن الشوارع الشريانية الطويلة الموجهة للسيارات قسّمت النسيج دون مركز واضح، والطلب تجاوز الطاقة المخططة مبكراً.</p>
                            <p class="text-[11px] text-slate-500">المصادر: مجلة Bidoun (Medinet Nasr) عن المساحة الأصلية وامتداد 1971 · ويكيبيديا العربية (مدينة نصر) للمساحة والسكان 2023. الرقمان من مصدرين ويختلفان لاختلاف نطاق الحدود، وكلاهما معروض كما ورد.</p>
                        </div>

                    <details class="um-det">
                        <summary>العاصمة الإدارية الجديدة (مصر) · عاصمة مخططة لتخفيف الازدحام عن القاهرة</summary>
                        <div class="um-in text-xs sm:text-sm space-y-2 leading-loose">

                            <p>المساحة المخططة <b>700 كم²</b> (نحو 170,000 فدان) ثم توسعت التخصيصات إلى نحو <b>223,383 فدان (≈ 907 كم²)</b>. السكان المستهدفون <b>6.5 مليون نسمة</b> وقد يرتفع الرقم إلى 7 ملايين. المرحلة الأولى (منذ 2016) تغطي أكثر من 40,000 فدان وتضم الحي الحكومي والبرلمان والقضاء والمنطقة المركزية للأعمال وأحياء سكنية، ضمن مخطط يشمل <b>21 حياً سكنياً</b> ومنطقة «النهر الأخضر».</p>
                            <p class="text-amber-300/90"><b>تنبيه على الأرقام:</b> هذه أرقام مستهدفة من المخطط وليست قيماً متحققة؛ السكان الفعليون الحاليون أقل بكثير ومتغيرون، والمرحلة الثانية (40,000 فدان إضافية) تأجلت إلى 2026 حسب المصدر.</p>
                            <p class="text-[11px] text-slate-500">المصادر: ويكيبيديا الإنجليزية (New Administrative Capital) للمساحات والمراحل · بوابة محافظة القاهرة (مارس 2021) لإعلان 700 كم² و6.5 مليون نسمة.</p>

            try {
                const raw = localStorage.getItem(STORAGE_KEY);
                if (raw) {
                    const parsed = JSON.parse(raw);
                    appState = { ...appState, ...parsed };
                } else {
                    // Pre-populate 1 sample brainstorm session so the log isn't empty on first visit
                    appState.brainstormLog = [
                        {

        function showToast(message, type = 'teal') {
            const container = document.getElementById('toast-container');
            const toast = document.createElement('div');
            const borderClass = type === 'amber' ? 'border-amber-500 bg-slate-900 text-amber-300' : 'border-teal-500 bg-slate-900 text-teal-300';
            toast.className = `px-4 py-2.5 rounded-xl border ${borderClass} shadow-2xl text-xs font-bold flex items-center gap-2 transition-all duration-300`;
            toast.innerHTML = `<i class="fa-solid fa-circle-check"></i> <span>${message}</span>`;
            container.appendChild(toast);
            setTimeout(() => {
                toast.style.opacity = '0';
                setTimeout(() => toast.remove(), 300);

        function switchTab(tabId) {
            let openAcc = null;
            if (TAB_ROUTE_ALIAS[tabId]) {
                openAcc = TAB_ROUTE_ALIAS[tabId].open || null;
                tabId = TAB_ROUTE_ALIAS[tabId].tab;
            }
            document.querySelectorAll('.tab-panel').forEach(p => p.classList.add('hidden'));
            const el = document.getElementById(`tab-${tabId}`);
            if (el) el.classList.remove('hidden');
            try { localStorage.setItem('um_active_tab', tabId); } catch(e) {}

            if (openAcc) {
                const acc = document.getElementById(openAcc);
                if (acc) { acc.open = true; setTimeout(() => acc.scrollIntoView({ behavior: 'smooth', block: 'start' }), 60); }
            }

            document.querySelectorAll('.tab-btn').forEach(btn => {
                btn.className = 'tab-btn shrink-0 px-3.5 py-2.5 rounded-xl text-xs sm:text-sm font-bold flex items-center gap-2 transition-all bg-slate-800/70 text-slate-300 hover:bg-slate-800 border border-slate-700/60';
            });
            const activeBtn = document.getElementById(`tab-btn-${tabId}`);
            if (activeBtn) {
                activeBtn.className = 'tab-btn active-tab shrink-0 px-3.5 py-2.5 rounded-xl text-xs sm:text-sm font-bold flex items-center gap-2 transition-all bg-gradient-to-l from-teal-600 to-teal-700 text-white shadow-lg shadow-teal-600/25 border border-teal-400/40';
            }
        }

        function togglePhaseAccordion(phaseId) {
            const phase = DEFAULT_ROADMAP.find(p => p.id === phaseId);
            if (phase) {
                // V22: if the pinned header is clicked mid-section, keep context after collapse
                var back = -1;
                if (phase.expanded) {
                    var head = document.getElementById('phase-head-' + phaseId);
                    var panel = document.getElementById('tab-learning');
                    var z = panel ? (parseFloat(panel.style.getPropertyValue('--um-z')) || 1) : 1;
                    var pin = head ? ((parseFloat(head.style.top) || 48) * z) : 0;
                    if (head && head.getBoundingClientRect().top <= pin + 4) {
                        back = head.parentElement.getBoundingClientRect().top + window.scrollY - pin - 8;
                    }
                }
                phase.expanded = !phase.expanded;
                renderRoadmap();
                if (back >= 0) { window.scrollTo({ top: Math.max(0, back), behavior: 'instant' }); }
            }
        }

        function expandAllPhases(expand) {

        }

            appState.topicNotes[topicId] = value;

        function updateGlobalProgressHeader() {
            let total = 0;
            let done = 0;
            DEFAULT_ROADMAP.forEach(p => {
                p.topics.forEach(t => {
                    total++;
                    if (appState.completedTopics[t.id]) done++;
                });
            });
            const pct = total > 0 ? Math.round((done / total) * 100) : 0;
            const txtEl = document.getElementById('header-progress-text');
            const barEl = document.getElementById('header-progress-bar');
            if (txtEl) txtEl.textContent = `${pct}% (${done}/${total})`;
            if (barEl) barEl.style.width = `${pct}%`;
        }

        function saveBrainstormSession() {
            const ctxKey = document.getElementById('bs-context-select').value;
            const title = document.getElementById('bs-project-title').value.trim() || 'مشروع تخطيطي بدون عنوان';
            const p1 = document.getElementById('bs-input-1').value.trim();
            const p2 = document.getElementById('bs-input-2').value.trim();
            const p3 = document.getElementById('bs-input-3').value.trim();
            const p4 = document.getElementById('bs-input-4').value.trim();

            if (!p1 && !p2 && !p3 && !p4) {
                showToast('يرجى كتابة فكرة واحدة على الأقل أو الضغط على "توليد مسودة استرشادية"', 'amber');
                return;
            }

            const newCard = {
                id: 'bs-' + Date.now(),
                date: new Date().toLocaleDateString('ar-EG', { year: 'numeric', month: 'short', day: 'numeric' }),
                context: BRAINSTORM_CONTEXTS[ctxKey].title,
                title,
                p1, p2, p3, p4
            };

            appState.brainstormLog.unshift(newCard);
            saveState();
            renderBrainstormLog();
            showToast('تم حفظ بطاقة العصف الذهني في سجل مشاريعك!');
        }

        function copyBrainstormCard(id) {
            const item = appState.brainstormLog.find(x => x.id === id);
            if (!item) return;
            const text = `مشروع: ${item.title}\nالسياق: ${item.context}\n\n1. الفكرة والهوية: ${item.p1}\n2. التدرج الكثافي: ${item.p2}\n3. الهيكل الأخضر والمناخ: ${item.p3}\n4. الحركة وإمكانية الوصول: ${item.p4}`;
            const ta = document.createElement('textarea');
            ta.value = text;
            document.body.appendChild(ta);
            ta.select();
            document.execCommand('copy');
            ta.remove();
            showToast('تم نسخ تفاصيل المشروع إلى الحافظة!');
        }

        function normalizeLandUsePercentages() {
            const r = parseFloat(document.getElementById('calc-pct-res').value) || 0;
            const rd = parseFloat(document.getElementById('calc-pct-roads').value) || 0;
            const op = parseFloat(document.getElementById('calc-pct-open').value) || 0;
            const fc = parseFloat(document.getElementById('calc-pct-fac').value) || 0;
            const cm = parseFloat(document.getElementById('calc-pct-com').value) || 0;
            const sum = r + rd + op + fc + cm;
            if (sum === 0) return;

            const nr = Math.round((r / sum) * 100);
            const nrd = Math.round((rd / sum) * 100);
            const nop = Math.round((op / sum) * 100);
            const nfc = Math.round((fc / sum) * 100);
            const ncm = 100 - (nr + nrd + nop + nfc);

            document.getElementById('calc-pct-res').value = nr;
            document.getElementById('calc-pct-roads').value = nrd;
            document.getElementById('calc-pct-open').value = nop;
            document.getElementById('calc-pct-fac').value = nfc;
            document.getElementById('calc-pct-com').value = Math.max(1, ncm);

            runMasterplanCalculator();
            showToast('تمت موازنة مجموع نسب الاستعمالات إلى 100% بالضبط');
        }
